# Goswami Travels

Frontend-only bus ticket booking experience built with React and Vite.

## Run locally

**Prerequisite:** Node.js

1. Install dependencies: `npm install`
2. Start the development server: `npm run dev`

The app has no backend. Booking and dashboard demo records are stored in the current browser's local storage and are not shared between devices. A booking is only a request; the operator must confirm it through WhatsApp.
